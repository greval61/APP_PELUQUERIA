Introducción

Génesis es una aplicación web local desarrollada para gestionar de forma eficiente las citas, cobros y la facturación básica de una peluquería. Este manual proporciona instrucciones claras para su instalación, puesta en marcha y operación diaria.

Requisitos y arranque

Instala Node.js y ejecuta los comandos desde la raíz del proyecto:

cd backend
npm install
npm start

cd frontend
npm install
npm start

Acceso a la aplicación

Abre la URL que lance el comando npm start del frontend. Introduce la contraseña si se solicita y pulsa Entrar.

Vista principal (Agenda / Calendario)

El calendario ofrece vistas día/semana/mes. Usa los botones superiores para filtrar por empleado, acceder a informes o cerrar sesión.

Crear, editar y eliminar citas

Selecciona un tramo horario para crear una cita o haz clic sobre una existente para editarla. Rellena los campos y pulsa Guardar. Para eliminar, pulsa Eliminar y confirma.

Buscar clientes

Usa el buscador (nombre/teléfono) con rango de fechas. Pulsa Buscar para ver resultados y selecciónalos para abrir la cita en el modal. Cancelar limpia campos.

Informes y exportación

La vista de informes permite extraer datos por periodo (mes/trimestre/año) y exportar a PDF. La función de exportación captura el contenido visual para generar el PDF.

Top servicios

El botón Ver Top servicios abre una ventana con los servicios más solicitados y su ingreso. Desde esa ventana se puede exportar a PDF sin controles visibles.

Resolución de problemas

  • Si no hay citas, comprueba que el backend en http://localhost:5000 está en marcha.
  • Si la exportación falla, revisa el permiso de popups y conexión a las librerías CDN.
